플레이에 집중하도록,
Kuan POE Helper

물약 쿨다운을 곁눈질로 확인하고, 검색한 아이템만 골라 옮기고, 지금 있는 지역의 레벨업 루트와 맵 지형을 화면 위에서 바로 봅니다. 설치 없이 실행 파일 하나로 동작합니다.

⬇ 최신 버전 다운로드 릴리즈 노트 보기 GitHub

Windows 10 / 11 · 관리자 권한 필요 · 별도 설치 과정 없음

게임 화면 위에서 바로

창을 따로 띄워 확인하는 게 아니라, 보고 있던 자리에 필요한 것만 얹습니다. 전부 위치·크기·투명도를 직접 정할 수 있고, 클릭은 그대로 게임에 전달됩니다.

오버레이

물약 쿨다운 막대

물약을 쓰면 남은 시간이 줄어드는 막대가 뜹니다. 숫자를 읽지 않고 곁눈질로 파악하도록 만들었습니다.

  • 슬롯마다 쿨다운을 따로 지정
  • 막대 색상·투명도·위치·크기 조절
  • 은신처에서는 자동으로 숨김 — 채팅으로 12345를 칠 때 뜨지 않도록
오버레이

스킬 쿨다운 막대

Q·W·E·R·T 스킬도 같은 방식으로. 물약과는 별개의 막대라서 HUD의 다른 자리에 따로 놓을 수 있습니다.

  • 물약과 독립된 위치·색상 설정
  • 긴 쿨다운 스킬(소환수, 이동기)에 특히 유용
오버레이

맵 레이아웃

지금 들어온 지역의 지형 그림이 자동으로 뜹니다. 지역 이름은 게임 로그에서 읽으므로 이동하면 그림도 알아서 바뀝니다.

  • 액트 1~10, 100개 지역 수록
  • 마우스를 올렸을 때만 조절 UI가 나타나고, 치우면 그림만 남음
  • 모서리를 끌어 크기 조절, 아무 곳이나 끌어 이동
오버레이

레벨업 루트

액트 1~10 루트를 화면 한쪽에 띄워두고 따라갑니다. 지역을 옮기면 해당 단계로 알아서 넘어갑니다.

  • 마지막으로 보던 줄을 기억 — 다시 열면 이어서
  • 액트 선택·검색·복사, 내용 직접 편집
  • 게임 위에 오래 떠 있는 창이라 어두운 테마

보관함 정리, 한 번에

게임 검색창에 입력하면 해당 아이템에 테두리가 생깁니다. 그 테두리를 화면에서 직접 읽어, 검색된 것만 골라 Ctrl+클릭으로 옮깁니다.

보관함 → 인벤토리

검색한 아이템만 가져오기

테두리가 생긴 아이템만 차례로 사라지는 것이 보입니다. 강조되지 않은 아이템은 그대로 남습니다.

  • 쿼드 보관함(24×24)과 일반 보관함(12×12) 지원
  • 아이템 테두리가 끊기지 않고 이어져 있는지로 판정 — 금색 아이템 그림에 속지 않음
  • 1×1부터 2×4까지 모든 크기를 하나의 아이템으로 인식
  • 해상도·UI 배율·모니터 감마가 달라도 동작하도록 설계
  • 한 번에 30개까지, 클릭 간격은 매번 불규칙
인벤토리 → 창고

인벤토리 통째로 비우기

단축키 한 번으로 인벤토리 60칸을 순서대로 Ctrl+클릭해 창고로 넘깁니다. 맵 한 판 돌고 온 뒤 정리에.

  • 클릭 간격은 매번 달라지고, 몇 번마다 조금 더 쉬어 갑니다
  • 속도는 설정 파일에서 조절 가능
  • 인벤토리가 가득 차 더 옮겨지지 않으면 스스로 멈추고 알려줍니다
오토클릭 홀드키

누르고 있는 동안 계속 클릭

지정한 키를 누른 채 커서를 훑으면 지나가는 아이템이 차례로 옮겨집니다. 정해진 순서가 아니라 원하는 것만 골라 담을 때.

  • Shift를 함께 누르면 창고 ↔ 인벤토리 이동에도 그대로
  • 오작동 방지를 위해 Ctrl 또는 Alt 조합만 지정할 수 있습니다
  • 반드시 인벤토리·보관함 안에서만 — 필드에서 쓰면 입력 과다로 접속이 차단될 수 있습니다
진단 도구

내 PC에서 제대로 인식되는지 확인

모니터와 해상도는 사람마다 다릅니다. 그래서 값을 추측하지 않고 실제 화면으로 맞출 수 있게 만들었습니다.

  • 보관함을 그대로 캡처해 인식 결과를 그려서 표시
  • 칸을 클릭하면 그 칸의 네 변 측정값 표시
  • '색상 마스크 보기'로 테두리가 색으로 잡히는지 확인

설정은 전부 화면 안에서

ini 파일을 열 일이 없습니다. 모든 단축키는 원하는 대로 다시 지정할 수 있습니다.

게임 단축키

필요한 동작을 키 하나로

  • 물약 매크로, 감정 주문서 우클릭, 길드 채팅 열기
  • 투겐 흥정, 화폐 반복 사용, CWDT 매크로
  • 연속 사용키 토글 — 키 5개를 순서대로, 불규칙한 간격으로
  • 오토클릭 홀드키 (Ctrl/Alt 조합만 허용)
  • 중복된 단축키는 저장 시 경고
물약

물약 매크로와 막대 설정

  • 사용할 슬롯을 체크하면 순서대로 입력 (사이사이 랜덤 딜레이)
  • 6번 슬롯은 원하는 키를 직접 지정
  • 쿨다운·색상·투명도·화면 위치를 여기서 한 번에
채팅 매크로

반복 입력은 매크로로

  • 거래 응대, 초대, /hideout 같은 문구를 표에서 편집
  • 'PoE 명령어에서 추가'로 자주 쓰는 명령을 골라 넣기
  • 문구마다 단축키를 따로 지정
레벨업

POE1 / POE2 각각

  • 게임별로 루트와 맵 레이아웃을 따로 관리
  • POE2 맵 레이아웃은 준비 중
링크 · 메모

자주 쓰는 것들을 한곳에

  • poe.ninja, PoE DB, 미궁, 크래프팅 등 기본 링크 10개 내장
  • 원하는 사이트를 추가하고 프로그램에서 바로 열기
메모

시세·정규식·빌드 링크 메모

  • 카드를 더블클릭해 내용 편집
  • 메모 안의 링크는 즐겨찾기로 등록 가능

그 밖에

📍

지역 자동 감지

클라이언트 로그를 읽어 지금 있는 곳을 판별합니다. 화면 인식이 아니라서 해상도·감마·UI 설정에 영향을 받지 않고, 은신처에서는 매크로와 오버레이를 알아서 멈춥니다.

🔄

자동 업데이트

새 버전이 올라오면 알려주고, 확인만 누르면 내려받아 설치한 뒤 자동으로 다시 시작합니다. 설정은 그대로 유지됩니다.

🖱️

오버레이는 클릭을 막지 않음

모든 오버레이는 클릭해도 활성화되지 않고, 클릭이 게임으로 그대로 전달됩니다. 오버레이 때문에 게임이 키 입력을 놓치는 일이 없습니다.

💾

설정 내보내기 / 가져오기

설정 전체를 파일 하나로 백업하고 다른 PC에서 그대로 불러옵니다.

🎯

좌표 캘리브레이션

보관함·인벤토리 영역을 드래그로 한 번만 지정하면 됩니다. 점선 격자가 실제 칸과 겹치도록 방향키로 1px씩 미세 조정할 수 있습니다.

📦

설치 없음 · 포터블

실행 파일 하나. 설정과 메모는 그 옆에 저장되므로 폴더째 옮기면 그대로 따라갑니다.

시작하기

내려받아 실행하면 끝입니다. 설치 마법사도, 레지스트리도 건드리지 않습니다.

  1. 실행 파일을 내려받습니다 위의 다운로드 버튼을 누르면 항상 가장 최신 릴리즈를 받게 됩니다.
  2. 원하는 폴더에 두고 실행합니다 설정과 메모는 실행 파일 옆에 저장되므로, 폴더째 옮기면 그대로 따라갑니다.
  3. 관리자 권한을 허용합니다 게임이 관리자 권한으로 돌아가기 때문에, 같은 권한이 아니면 키 입력이 전달되지 않습니다.
  4. 좌표를 한 번 맞춥니다 보관함 정리처럼 화면을 클릭하는 기능은 '좌표 캘리브레이션' 탭에서 영역을 한 번만 지정하면 됩니다.
알아두면 좋은 점
  • Windows 10 / 11 64비트에서 동작합니다.
  • 오버레이가 보이려면 게임을 전체 화면 창 모드로 실행해 주세요. 전용 전체 화면에서는 어떤 오버레이도 표시되지 않습니다.
  • 오토클릭은 반드시 인벤토리·보관함 안에서만 사용하세요. 필드에서 쓰면 입력 과다로 접속이 차단될 수 있습니다.
  • 처음 실행할 때 백신이 경고할 수 있습니다. 키보드 후킹을 사용하는 프로그램에서 흔한 오탐입니다.
