# web/shots — 소개 페이지 스크린샷

`web/index.html`이 참조하는 이미지들입니다. **파일 이름(확장자 앞부분)이 정확히 일치해야** 표시됩니다.

## 확장자는 아무거나 — png / gif / webp / mp4

페이지가 알아서 찾습니다. `flask-bars` 자리에 넣을 파일이 GIF라면 **`flask-bars.gif`로 저장하기만 하면 됩니다.**
HTML은 손대지 않아도 됩니다.

찾는 순서는 `.png` → `.gif` → `.webp` → `.mp4` 이고, 하나라도 있으면 그것을 씁니다.
`.mp4`는 자동 재생·무음·반복되는 영상으로 표시됩니다.
아무것도 없으면 깨진 아이콘 대신 "없음" 안내 상자가 나오므로, 하나씩 채워도 페이지는 계속 정상으로 보입니다.

## 만들 때

**정지 이미지**는 PNG로. 글자와 선이 많아서 JPG로 저장하면 뭉개집니다.

**움직이는 것**은 3~6초짜리 짧은 반복이면 충분합니다. 길수록 용량만 커지고 전달되는 건 같습니다.

- GIF는 **한 파일 3MB 이하**를 목표로 하세요. 색 수를 줄이거나(128색), 프레임을 12~15fps로,
  캡처 영역을 필요한 부분만 잘라내면 대부분 들어갑니다.
- 더 긴 영상이나 화면이 큰 장면은 **MP4가 GIF보다 5~10배 작습니다.** `.mp4`로 저장하면
  자동 재생·무음·반복으로 표시되니 GIF 대신 써도 됩니다.
- 만들 도구: [ScreenToGif](https://www.screentogif.com) (녹화·편집·최적화가 한 번에),
  [ShareX](https://getsharex.com), 용량 줄이기는 [ezgif.com/optimize](https://ezgif.com/optimize).

공통:

- 창 전체보다 **해당 영역만** 잘라내는 편이 페이지에서 잘 보입니다.
- 오버레이(막대·맵 레이아웃)는 게임 화면 위에 있는 그대로 찍어야 실제 느낌이 전달됩니다.
- 계정 이름, 캐릭터 이름, 귓속말이 들어가지 않았는지 확인하세요.

## 넣고 나서

`web/index.html`을 브라우저로 열어 확인한 뒤 커밋하면 Vercel이 자동으로 다시 배포합니다.
페이지 전체 용량이 15MB를 넘어가면 처음 열릴 때 눈에 띄게 느려지므로, 그 전에 한 번 줄여주세요.
